# Добавить флаг `--total-only`

Сокращённая выдержка из задания, которое Context Pilot передал второй сессии после остановки первой.

## Цель

В CLI учёта рабочего времени добавьте флаг `--total-only`. Он печатает только сумму минут за период и перевод строки. Существующие форматы вывода и данные примера должны сохраниться.

## Состояние при передаче

Предыдущая сессия завершилась с ошибкой. Два файла уже изменены в рабочей копии:

    M work-time.js
    M work-time.test.js

Сверьте сделанное с файлами на диске, сохраните подходящие изменения и закончите оставшуюся работу. Для контекста откройте также `work-time-report.js`, `json-export.test.js` и `examples/work-time.json`.

## Как проверить результат

- За 1–2 ноября 2026 года пример печатает `95` и перевод строки.
- Для периода без записей — `0` и перевод строки.
- Вместе с `--json` или `--csv` флаг должен давать ошибку без вывода в stdout.
- Запустите `npm test` отдельной командой. Ожидаемый код завершения — 0.
